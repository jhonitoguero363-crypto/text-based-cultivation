## 规则摘要

| 项 | 说明 |
|----|------|
| 与法术区别 | **功法**同时仅修习一门；法术见 [法术设定](./法术设定.md) |
| 筛选 | 功法阁「功法」Tab 按 **品阶**（黄 / 玄 / 地 / 天 / 仙）浏览 |
| 派系可见 | **魔修**仅魔门宗门；**妖族**流派仅妖族宗门；**剑修**与**炼体（体修）**各宗通用；其余通用目录各宗可见 |
| 坊市 | 仅上架各宗通用功法；派系专属不出现在坊市 |
| 兑换 | 消耗宗门贡献；需达到适合境界；兑换后自动设为修习中 |
| 改修 | 已收录功法可随时改修，原功法仍保留；**由低品阶改修至更高品阶会损耗修为**（每跨 1 小阶约 8%，上限 48%）；同阶或降阶不损 |
| 流派 | 十四流派（十二通用 + 魔修 / 妖族），每部功法归属其一 |
| 属性 | 九种：金 / 木 / 水 / 火 / 土 / 风 / 冰 / 雷 / **无属性**；影响洞府修炼灵根亲和与异灵根战力 |
| 功法熟练度 | 洞府修炼增长点数；六阶与法术相同；**当前修习中**功法按阶位加战力与修为获取 |
| 品阶与修为 | 品阶越高洞府修为倍率越高（`getTechniqueGradeExpMult`），与境界突破需求大致同步 |

> **与战斗对齐**：战斗不结算「属性伤害%/闪避%/防御%」等目录旧文案；机械效果为战力倍率、吐纳与突破相关。目录 `effect` 字段保留风味（UI 经 `alignCombatLoreText` 标注），以熟练度与 `combat-power.ts` 为准。

## 熟练度阶位

数据来源：`src/constants/technique-proficiency.ts`（阈值同法术）。

| 阶 | 熟练度 | 名称 | 效果 |
|----|--------|------|------|
| 1 | 0～99 | 初窥门径 | 功法基础效果 |
| 2 | 100～299 | 略有小成 | 战力 +5%，修为获取 +5% |
| 3 | 300～699 | 登堂入室 | 战力 +10%，修为获取 +10% |
| 4 | 700～1499 | 融会贯通 | 战力 +18%，修为获取 +15% |
| 5 | 1500～2999 | 出神入化 | 战力 +30%，修为获取 +25% |
| 6 | ≥3000 | 炉火纯青 | 战力 +50%，修为获取 +40% |

洞府修炼功法时约每 5 秒增加修为：随机吐纳 × 悟性/灵根/洞府 × **境界基础** × **功法品阶倍率**（黄下≈0.85～仙上≈3.1）×（1+熟练度修为加成），并增加 **0～0.5** 熟练度（受悟性倍率，封顶 0.5）。境界越高突破需求涨得更快，需换更高阶功法才能跟上。进阶时提示境界名称。仅 **当前修习中** 的功法熟练度计入战力。
