# 法术设定

功法阁 · 法术目录，共 **52** 门（含生活法术：炼丹术、炼器术）。

数据来源：`法术信息.txt` → `src/constants/spell-catalog.ts`。

## 规则摘要

| 项 | 说明 |
|----|------|
| 与功法区别 | **功法**同时仅修习一门；**法术**可同时修习多门 |
| 入口 | 功法阁 →「法术」Tab |
| 筛选 | 黄 / 玄 / 地 / 天 / 仙 |
| 兑换 | 消耗宗门贡献；需达到品阶对应境界 |
| 背包分类 | `法术`（与功法分栏） |
| 生活法术 | **炼丹术** → 丹阁炼制；**炼器术** → 器阁打造 |
| 法术熟练度 | 洞府演练增长点数；六阶见下表；自己炼制成功率受对应炼制法术熟练度影响 |
| 与功法互斥 | 洞府中功法与法术不可同时修炼 |

## 熟练度阶位

数据来源：`法术熟练度.txt` → `src/constants/spell-proficiency.ts`。

| 阶 | 熟练度 | 名称 | 效果 |
|----|--------|------|------|
| 1 | 0～99 | 初窥门径 | 法术基础效果 |
| 2 | 100～299 | 略有小成 | 法术威力 +5% |
| 3 | 300～699 | 登堂入室 | 法术威力 +10%，灵力消耗 -5% |
| 4 | 700～1499 | 融会贯通 | 法术威力 +18%，冷却 -10% |
| 5 | 1500～2999 | 出神入化 | 法术威力 +30%，灵力消耗 -15% |
| 6 | 3000+ | 炉火纯青 | 法术威力 +50%，有概率触发特殊效果 |

洞府演练法术时约每 5 秒增加 **0～0.5** 熟练度（受悟性倍率，封顶 0.5），**不增加修为**。进阶时提示境界名称。
