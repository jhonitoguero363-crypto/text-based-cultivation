# 法术设定

功法阁 · 法术目录，共 **52** 门（含生活法术：炼丹术、炼器术）。

数据来源：`法术信息.txt` → `src/constants/spell-catalog.ts`。

## 规则摘要

| 项 | 说明 |
|----|------|
| 与功法区别 | **功法**同时仅修习一门；**法术**可同时修习多门 |
| 入口 | 功法阁 →「法术」Tab |
| 筛选 | 黄 / 玄 / 地 / 天 / 仙 |
| 兑换 | 消耗宗门贡献；需达到品阶对应境界 |
| 背包分类 | `法术`（与功法分栏） |
| 属性 | 九种：金 / 木 / 水 / 火 / 土 / 风 / 冰 / 雷 / **无属性**（与功法一致；影响洞府演练灵根亲和、**出战属性克制**） |
| 生活法术 | **炼丹术** → 丹阁炼制；**炼器术** → 器阁打造（均为无属性；**不可出战**） |
| 出战法术 | 人物详情最多选 **3** 门计入战力与交手克制；未选手动时按熟练自动取前 3（克制简表不在详情页展示） |
| 法术熟练度 | 洞府演练增长点数；六阶见下表；**战斗向**加成出战战力；炼丹/炼器加成炼制成功率 |
| 与功法互斥 | 洞府中功法与法术不可同时修炼 |

> **与战斗对齐**：战斗为战力比对 + 属性克制，无独立「灵力 / 冷却 / 伤害%」结算。目录中旧「威力/护盾/复活」等句视为设定风味（UI 经 `alignCombatLoreText` 标注），机械效果以上表与 `combat-power.ts` / `adventure-battle.ts` 为准。

## 熟练度阶位

数据来源：`法术熟练度.txt` → `src/constants/spell-proficiency.ts`。

| 阶 | 熟练度 | 名称 | 效果 |
|----|--------|------|------|
| 1 | 0～99 | 初窥门径 | 法术基础；出战贡献战力与属性克制 |
| 2 | 100～299 | 略有小成 | 出战战力贡献 +5%（炼丹/炼器为成功率） |
| 3 | 300～699 | 登堂入室 | 出战战力贡献 +10%（炼丹/炼器成功率提升） |
| 4 | 700～1499 | 融会贯通 | 出战战力贡献 +18% |
| 5 | 1500～2999 | 出神入化 | 出战战力贡献 +30% |
| 6 | 3000+ | 炉火纯青 | 出战战力贡献 +50% |

洞府演练法术时约每 5 秒增加 **0～0.5** 熟练度（受悟性倍率，封顶 0.5），**不增加修为**。进阶时提示境界名称。

秘境**击败妖兽 / 人物**可增长**出战法术**熟练度（约 0.1～0.5；优先克制/契合属性）。交手前展示胜率与克制。
