# 玩法系统

## 角色创建

1. 输入道号、选择性别
2. 随机灵根
3. 初始境界：炼气一层
4. 初始灵石：100
5. 法宝 / 灵宠 / 功法 / 宗门初始为空，随后拜入宗门

## 宗门日常

### 任务堂

- 按**天元历日**刷新任务板（约 5 个槽位）；现实 **6 小时 = 1 日**（农历风格月日）
- 换日时**未完成任务保留**（进行中 / 未接取），已完成移除后补新
- **同时仅可接取 1 个**进行中任务
- 接取后到角色页完成或取消
- 完成后槽位补新任务；无每日完成次数硬上限
- 类型标签：每日 / 悬赏 / 周常 / 随机等（奇遇不走宗门任务板）

### 矿洞

- 无每日挖矿次数上限（仅统计今日已挖次数）
- 开始后立即挖一次，之后每 **5 秒**挖一次
- 可能空手；也可能获得矿石或灵石（灵石不再分品级，仅计数量）
- 修为越高，高阶矿权重与单次灵石数量略升

### 药园

- 消耗灵石兑换药材
- 按品阶筛选：全部 / 灵草 / 灵药 / 灵果 / 神 / 仙 / 道

### 器阁

- **打造法宝**：需先修习法术「炼器术」
  - **自己炼制**：不耗灵石；成功率由炼器术等级 + 预估法宝品阶（材料强度略加成）决定；失败材料尽毁
  - **委托炼制**：缴纳灵石；必定成功
- **法宝买卖**：按境界浏览目录购入；可回售仓库法宝（无需炼器术）

### 丹阁

- **炼制丹药**：需先修习法术「炼丹术」
  - **自己炼制**：不耗灵石；成功率由炼丹术等级 + 丹药品阶决定；失败药材尽毁
  - **委托炼制**：缴纳配方灵石；必定成功
- **丹药买卖**：无需炼丹术

### 灵兽阁

- **只售灵宠**（驯化目录）；野妖不在此售
- 可回售：兽阁灵宠 + 秘境抓捕的妖兽

### 其他设施（占位 / 轻量）

- 功法阁（功法同时仅一门；法术可多门）、洞府、思过崖、镇妖塔、人物拜访
- 详见 [功法设定](./功法设定.md)、[法术设定](./法术设定.md)

## 历练

### 坊市

- 分类：丹药 / 功法 / 法宝 / 材料
- **修历日随机货架**（品类抽取、价格浮动、库存有限）；换日自动更新，**不可手动刷新**
- 境界影响可上架池；同日内货架不因境界变化重抽

### 秘境探索

- 选择地点后进入探索
- 每日探索次数有限（默认约 8 次）
- 每次可遭遇 1～3 只妖兽
- 较高概率偶遇人物；约 **28%** 触发奇遇
- 击败妖兽获得掉落材料；**击败后可抓捕**化为灵宠（按稀有度成功率）
- 抓捕的妖兽可带到灵兽阁出售
- 完整地点表（危险度、掉落、收益估算）见 [秘境设定](./秘境设定.md)

## 法宝装备

- 最多装备 **4** 件
- 按类别占位：攻击位 / 防御位 / 辅助位 / 特殊位
- 同类仅一件，新装备替换同槽

- 图鉴汇总收录进度；矿石 / 药材 / **灵兽**（灵宠∪妖兽）等已接图鉴图标
