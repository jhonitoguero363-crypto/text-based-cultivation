# 玩法系统

## 角色创建

1. 输入道号、选择性别
2. 随机灵根与悟性（悟性约 20～99，多数落在中段，与灵根独立）
3. 初始境界：**无修为**（最低境界；突破后进入炼气一层）
4. 初始灵石：100
5. 法宝 / 灵宠 / 功法 / 宗门初始为空，随后拜入宗门

## 宗门日常

### 月俸

- 天元历**每月初一**按人物身份发放灵石；若月初未登录，当月首次进入游戏时补发
- 入宗当月即按当前身份领取；散修不发
- 数额见 [宗门设定](./宗门设定.md)

### 任务堂

- 按**天元历日**刷新任务板（约 5 个槽位）；现实 **6 小时 = 1 日**（农历风格月日）
- 换日时**未完成任务保留**（进行中 / 未接取），已完成移除后补新
- **同时仅可接取 1 个**进行中任务
- 接取后到角色页完成或取消
- 完成后槽位补新任务；无每日完成次数硬上限
- 类型：任务堂分 **通用** / **特色**（特色依赖本宗特色建筑）；板面标签仍为每日 / 悬赏 / 周常 / 随机；历练奇遇不走任务板，见 [奇遇设定](./奇遇设定.md)
- **设施前置**：依赖特色建筑的周常（试炼妖塔 / 魔窟试炼 / 剑冢问剑 / 返祖试炼）仅当本宗拥有对应设施时才可能刷出
- **文案宗门化**：目录用中性设施名（宗门矿洞 / 灵兽阁 / 丹阁）；任务堂与角色页按当前宗门替换展示（如青云矿洞、天魔矿洞）；见 `mission-localize.ts`
- **招收弟子**（`recruit_disciples`）：接取后在历练「坊市」出现招收按钮；点一次招入 **3** 名新弟子（随机姓名、随机根骨，身份依根骨与宗门等级），写入人物名录并持久化；进度达成后回角色页领奖

### 矿洞

- 无每日挖矿次数上限（仅统计今日已挖次数）
- 开始后立即挖一次，之后每 **5 秒**挖一次
- 可能空手；也可能获得矿石或灵石（灵石不再分品级，仅计数量）
- 修为越高，高阶矿权重与单次灵石数量略升

### 药园

- 消耗灵石兑换药材
- 按品阶筛选：全部 / 灵草 / 灵药 / 灵果 / 神 / 仙 / 道

### 器阁

- **打造法宝**：需先修习法术「炼器术」；可投入 **矿石** 与历练 **材料**（妖兽/奇遇掉落）
  - **自己炼制**：不耗灵石；成功率由炼器术等级 + 预估法宝品阶（材料强度略加成）决定；失败投入尽毁
  - **委托炼制**：缴纳灵石；必定成功
  - 材料强度：矿石按品阶；历练材料按来源妖兽境界折算
- **法宝买卖**：按境界浏览目录购入；可回售仓库法宝（无需炼器术）

### 丹阁

- **炼制丹药**：需先修习法术「炼丹术」
  - **自己炼制**：不耗灵石；成功率由炼丹术等级 + 丹药品阶决定；失败药材尽毁
  - **委托炼制**：缴纳配方灵石；必定成功
- **丹药买卖**：无需炼丹术
- **丹药服用**（八类效果，详见 [丹药设定](./丹药设定.md)）：
  - 角色页背包点按服用；**突破丹**、**保命丹**不可手动服
  - **突破丹**：洞府破境时弹窗选择是否服用（成败均消耗）
  - **保命丹**：身死时自动从背包触发；涅槃/逆命 → 正常，九死还魂/九转轮回 → 受伤
  - 灵根丹永久加灵根（可指定五行 / 单系；圣灵丹极低概率强化风冰雷）；修为丹加本层修为；悟性丹可临时加悟性点数或领悟倍率；聚灵丹临时加速洞府修炼；战斗丹临时加战力（可疗伤）；特殊丹部分玩法待开放

### 灵兽阁

- **只售灵宠**（驯化目录）；野妖不在此售
- 可回售：兽阁灵宠 + 秘境抓捕的妖兽
- 喂养涨好感（任务进度）；**养成 / 升级暂无**，出战战力按获取时锚定（见 [待完善功能](./待完善功能.md)）

### 人物拜访

- 可邀请历练、切磋、赠礼、双修等
- **亲密提升**：赠送药材/丹药、邀请同行、**共同完成历练**（点击「历练结束」时每位同行）、切磋等均可增加亲密
- **LLM 交谈**：拜访页可与对方对白；成功时亲密可按本轮 `intimacyDelta`（-3～+5）变化，并更新对方对「结伴 / 切磋 / 收礼」意愿（拒绝则挡对应行动；勉强减半收益；乐意额外 +1）。**口吻随双方地位差与当前亲密档共同变化**（上位简慢、下位恭敬；低亲密戒备、高亲密热络）。细则见 [LLM对话接入](./LLM对话接入.md)
- **找出卧底**（任务 `find_mole`）：非自身弟子 **≥2** 才刷出/可接；接取后随机指定一名同门为卧底；拜访该人时显示「卧底提示」与「卧底交谈」；点击生成对白文案后任务进度达成，亲密 +3
- **护送灵材 / 丹阁送药**：同样需非自身弟子 **≥2**，否则任务堂不刷、不可接取

| 行为 | 亲密变化 |
|------|----------|
| 赠送药材 / 丹药 | +8（受交谈收礼意愿修正） |
| 邀请历练同行 | +2（受结伴意愿修正） |
| 共同完成历练（历练结束） | 每位同行 +5 |
| 切磋比武 | 胜 +2（受切磋意愿修正）；负 0 |
| 寻访交谈 / 营救交谈 / 卧底交谈 | +3 / +5 / +3 |
| LLM 闲聊（成功） | -3～+5 / 次 |
| 退出宗门（对该宗人物） | 亲密保留约 20% |

### 退出与转宗

- 宗门页可「退出宗门」；退出后该宗**不可再入**
- 贡献清零、身份回散修、任务堂清空；与该宗人物亲密度大幅降低
- 若再加入**敌对派系**宗门（正道、魔门、妖族互为敌对），历练探索遇势均力敌之敌时强制交手 **100%** 触发

- 亲密上限 **100**；档位：陌生 / 面善 / 相识 / 熟识 / 亲近 / 莫逆（≥80）
- **初始亲密**：本宗按人物态度种子（中立约 10、友善约 25 等）；**敌对派系**人物首次接触再压低（约原值 25%，且不超过 3），同派非本宗不压低
- **邀请双修**：仅对**异性**且亲密 **≥80** 显示；邀至洞府后可开始双修
  - 洞府双修类似修炼功法：每 **5 秒**吐纳一次并展示累计收益
  - **只增加修为**（不增功法/法术熟练度）；本层修为已满则无收益
  - 可与功法/法术修炼互斥；「请回」可解除双修对象
- **切磋比武**：点到为止；交手前弹窗预览战力 / 胜率 / 克制；按战力判定胜负（可负）
  - **无论胜负**，任务进度（如周常「宗门斗法」）均 +1
  - **胜**：亲密 +2；较高概率涨已习法术熟练 / 修为
  - **负**：亲密不变；奖励减半或无；约 **4%** 受伤
  - 受伤期间战力约 **-30%**，不宜再战 / 切磋 / 死斗
- **生死比斗**（仅宗门同门）：交手前预览含阵亡/受伤约估与保命丹提示；按战力判定胜负（展示战力 = 结算战力）
  - **胜**：尽夺对方随身资源（灵石 / 药材 / 矿石 / 丹药 / 法宝），并被执法堂押往**思过崖**面壁
  - **败**：可能重伤或身死道消（规则同秘境交手；保命丹可免陨落）
- 面壁期间不可外出历练 / 交手；**不提供修为**（惩罚向）
- **面壁奇遇**：每 10 秒判定一次，约 1% 概率触发；可能获得高阶药材/矿石，或提升当前功法 / 已习法术熟练度
- **面壁锁定**：刑期未满不可离开思过崖界面（返回无效；误入其他页会强制拉回）

## 历练

### 坊市

- 分类：丹药 / 功法 / 法宝 / 药材 / 矿石（随机上架售卖）
- 下方 **统一回收**：仅显示背包持有（丹药 / 药材 / 矿石 / 材料），按参考市价 **80%** 回收；**宗门功法阁可兑换的功法与法术不可回收**
- **修历日随机货架**（品类抽取、价格浮动、库存有限）；换日自动更新，**不可手动刷新**
- 境界影响可上架池；同日内货架不因境界变化重抽
- **稀有丹药**：极小概率（约 **3.5%**）额外上架 1 枚坊市专属丹（不可炼制、不进丹阁）；品阶越高越稀有；**灵根 / 悟性 / 保命**类售价更高、出现更稀（详见 [丹药设定](./丹药设定.md)）
- **坊市人物**：四类——**商人 / 正道修士 / 魔道修士 / 散修**；正道、魔道优先抽自**其他宗门**对应派系名录；每日随机 2～4 人，可拜访、邀请历练等
- **商人拜访**：行商私货 3 件，品阶略高于玩家当前大境界（丹药 / 功法 / 法宝 / 药材 / 矿石），随日刷新；抽到丹药时约 **14%** 为稀有丹

### 秘境探索

- 选择地点后进入探索
- 每日探索次数有限（默认约 8 次）
- **同行人员**：可在宗门「人物」拜访时「邀请历练」，最多 **3** 人；历练页可查看/移除；**历练结束后清空**，下次需重新邀请；邀请与共同完成历练均提升亲密
- 每位同行使探索与击败收益约 **+8%**（最多 +24%）
- 每次可遭遇 1～3 只妖兽
- 探索极小概率拾得**药材 / 矿石**（各自约 4%，品阶随地点境界）
- 较高概率偶遇人物（约 70%）：**宗门弟子**为本宗弟子；**正道 / 魔道 / 妖族**为其他宗门对应派系人物；另混入散修、商人、隐世、奇遇；约 **28%** 触发奇遇任务
- **强制交手**：约 **28%** 概率遭遇势均力敌之敌（战力约我方含同行的 **88%～112%**）；约半为妖兽、半为敌对势力（正道、魔门、妖族互为敌对）；弹窗展示双方战力、预估胜率、属性克制、战败阵亡/受伤约估与保命丹持有后须应战（受伤 / 思过崖中不触发）。**叛出后入敌对派系宗门**时，该概率升为 **100%**
- **击败妖兽**：先预览再战；按战力差 + 属性克制（约 ±10% 胜率，总胜率约 8%～95%）判定。胜利获微量修为、出战法术熟练度（**不给灵石**）；随后可选 **击杀**（掉落材料）或 **抓捕**（仅一次；成功只得灵宠，失败自动转击杀并掉落）；出战灵兽可能依战力差阵亡；胜负短句绑定出战法术与克制
- **击败人物**：同样先预览再判定；胜利获灵石、微量修为、出战法术熟练度；小概率掉对应境界法宝，极小概率掉对应境界丹药；出战灵兽可能依战力差阵亡
- **战败**：依战力差可能 **阵亡**（弹窗 → 清空存档重开角色）或 **受伤**（战力约 -30%；洞府静养或疗伤丹药后方可再战），亦可能侥幸脱身；预览含阵亡/受伤约估与保命提示
- 抓捕的妖兽可带到灵兽阁出售
- 出战灵兽阵亡：我方战力 = 玩家战力 + 同行战力（同行已 ×0.3）；敌方越强，阵亡概率越高（约 2%～42%）
- **历练同行**：名录战力入库，交手合计 × **0.3**（展示=结算）
- 疗伤：洞府页「疗伤」静养免费痊愈；或服用疗伤向战斗丹（角色页可一键服药）；亦可背包点按丹药
- **保命**：保命丹不可手动服用；秘境 / 死斗判定身死时自动从背包触发（高价优先），免于陨落重开；触发后依丹药进入正常或受伤（详见 [丹药设定](./丹药设定.md)）
- 完整地点表（危险度、掉落、收益估算）见 [秘境设定](./秘境设定.md)
- 历练对战 / 探索掉落总览见 [历练对战掉落](./历练对战掉落.md)
- 击杀妖兽材料总表见 [历练妖兽掉落](./历练妖兽掉落.md)
- 奇遇了结材料总表见 [历练奇遇掉落](./历练奇遇掉落.md)（当前多为待补充）
- 战斗常量：`src/constants/adventure-battle.ts`（含强制交手、克制表、交手 preview、胜负文案、同行折算）
- 战力公式 / 境界锚点 / 出战法术：`src/constants/combat-power.ts`
