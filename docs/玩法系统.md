# 玩法系统

## 角色创建

1. 输入道号、选择性别
2. 随机灵根与悟性（悟性约 20～99，多数落在中段，与灵根独立）
3. 初始境界：**无修为**（最低境界；突破后进入炼气一层）
4. 初始灵石：100
5. 法宝 / 灵宠 / 功法 / 宗门初始为空，随后拜入宗门

## 宗门日常

### 月俸

- 天元历**每月初一**按人物身份发放灵石；若月初未登录，当月首次进入游戏时补发
- 入宗当月即按当前身份领取；散修不发
- 数额见 [宗门设定](./宗门设定.md)

### 任务堂

- 按**天元历日**刷新任务板（约 5 个槽位）；现实 **6 小时 = 1 日**（农历风格月日）
- 换日时**未完成任务保留**（进行中 / 未接取），已完成移除后补新
- **同时仅可接取 1 个**进行中任务
- 接取后到角色页完成或取消
- 完成后槽位补新任务；无每日完成次数硬上限
- 类型标签：每日 / 悬赏 / 周常 / 随机等（奇遇不走宗门任务板）

### 矿洞

- 无每日挖矿次数上限（仅统计今日已挖次数）
- 开始后立即挖一次，之后每 **5 秒**挖一次
- 可能空手；也可能获得矿石或灵石（灵石不再分品级，仅计数量）
- 修为越高，高阶矿权重与单次灵石数量略升

### 药园

- 消耗灵石兑换药材
- 按品阶筛选：全部 / 灵草 / 灵药 / 灵果 / 神 / 仙 / 道

### 器阁

- **打造法宝**：需先修习法术「炼器术」；可投入 **矿石** 与历练 **材料**（妖兽/奇遇掉落）
  - **自己炼制**：不耗灵石；成功率由炼器术等级 + 预估法宝品阶（材料强度略加成）决定；失败投入尽毁
  - **委托炼制**：缴纳灵石；必定成功
  - 材料强度：矿石按品阶；历练材料按来源妖兽境界折算
- **法宝买卖**：按境界浏览目录购入；可回售仓库法宝（无需炼器术）

### 丹阁

- **炼制丹药**：需先修习法术「炼丹术」
  - **自己炼制**：不耗灵石；成功率由炼丹术等级 + 丹药品阶决定；失败药材尽毁
  - **委托炼制**：缴纳配方灵石；必定成功
- **丹药买卖**：无需炼丹术

### 灵兽阁

- **只售灵宠**（驯化目录）；野妖不在此售
- 可回售：兽阁灵宠 + 秘境抓捕的妖兽

### 人物拜访

- 可邀请历练、切磋、赠礼、双修等
- **亲密提升**：赠送药材/丹药、邀请同行、**共同完成历练**（点击「历练结束」时每位同行）、切磋等均可增加亲密
- **邀请双修**：仅对**异性**且亲密 **≥80** 显示；邀至洞府后可开始双修
  - 洞府双修类似修炼功法：每 **5 秒**吐纳一次并展示累计收益
  - **只增加修为**（不增功法/法术熟练度）；本层修为已满则无收益
  - 可与功法/法术修炼互斥；「请回」可解除双修对象
- **切磋比武**：点到为止；任务进度与亲密照常提升
  - 约半数概率增长**已习法术熟练度**（随机一门，微量）
  - 约半数概率增长**修为**（随境界缩放；本层已满则不加）
  - **极低概率受伤**（约 2.5%）；受伤期间战力约 **-30%**，不宜再战 / 切磋 / 死斗
- **生死比斗**（仅宗门同门）：按战力判定胜负
  - **胜**：尽夺对方随身资源（灵石 / 药材 / 矿石 / 丹药 / 法宝），并被执法堂押往**思过崖**面壁
  - **败**：可能重伤或身死道消（规则同秘境交手）
- 面壁期间不可外出历练 / 交手；**不提供修为**（惩罚向）
- **面壁奇遇**：每 10 秒判定一次，约 1% 概率触发；可能获得高阶药材/矿石，或提升当前功法 / 已习法术熟练度
- **面壁锁定**：刑期未满不可离开思过崖界面（返回无效；误入其他页会强制拉回）

### 其他设施（占位 / 轻量）

- 功法阁（功法同时仅一门；法术可多门）、洞府、镇妖塔
- **洞府疗伤**：受伤时洞府页出现「疗伤」按钮，可**静养免费痊愈**；亦可在角色页服用疗伤丹药
- **洞府双修**：亲密 ≥80 的异性被邀请后，洞府出现双修栏；每 5 秒仅增修为
- 详见 [功法设定](./功法设定.md)、[法术设定](./法术设定.md)

## 历练

### 坊市

- 分类：丹药 / 功法 / 法宝 / 药材 / 矿石（随机上架售卖）
- 下方 **统一回收**：仅显示背包持有（丹药 / 药材 / 矿石 / 材料），按参考市价 **80%** 回收；**宗门功法阁可兑换的功法与法术不可回收**
- **修历日随机货架**（品类抽取、价格浮动、库存有限）；换日自动更新，**不可手动刷新**
- 境界影响可上架池；同日内货架不因境界变化重抽
- **坊市人物**：四类——**商人 / 正道修士 / 魔道修士 / 散修**；正道、魔道优先抽自**其他宗门**对应派系名录；每日随机 2～4 人，可拜访、邀请历练等
- **商人拜访**：行商私货 3 件，品阶略高于玩家当前大境界（丹药 / 功法 / 法宝 / 药材 / 矿石），随日刷新

### 秘境探索

- 选择地点后进入探索
- 每日探索次数有限（默认约 8 次）
- **同行人员**：可在宗门「人物」拜访时「邀请历练」，最多 **3** 人；历练页可查看/移除；**历练结束后清空**，下次需重新邀请；邀请与共同完成历练均提升亲密
- 每位同行使探索与击败收益约 **+8%**（最多 +24%）
- 每次可遭遇 1～3 只妖兽
- 探索极小概率拾得**药材 / 矿石**（各自约 4%，品阶随地点境界）
- 较高概率偶遇人物（约 70%）：**宗门弟子**为本宗弟子；**正道 / 魔道 / 妖族**为其他宗门对应派系人物；另混入散修、商人、隐世、奇遇；约 **28%** 触发奇遇任务
- **击败妖兽**：先按战力差判定胜负（胜率约 8%～95%）。胜利获微量修为、法术熟练度（**不给灵石**）；随后可选 **击杀**（掉落材料）或 **抓捕**（仅一次；成功只得灵宠，失败自动转击杀并掉落）；出战灵兽可能依战力差阵亡
- **击败人物**：同样先判定胜负；胜利获灵石、微量修为、法术熟练度；小概率掉对应境界法宝，极小概率掉对应境界丹药；出战灵兽可能依战力差阵亡
- **战败**：依战力差可能 **阵亡**（弹窗 → 清空存档重开角色）或 **受伤**（战力约 -30%；洞府静养或疗伤丹药后方可再战），亦可能侥幸脱身
- 抓捕的妖兽可带到灵兽阁出售
- 出战灵兽阵亡：我方战力 = 玩家战力 + 同行战力；敌方越强，阵亡概率越高（约 2%～42%）
- 疗伤：洞府页「疗伤」静养免费痊愈；或服用疗伤丹药（类型为恢复 / 复活 / 重生 / 造化，或名称含疗伤、凝血、回灵等；角色页可一键服药）
- 完整地点表（危险度、掉落、收益估算）见 [秘境设定](./秘境设定.md)
- 击杀妖兽材料总表见 [历练妖兽掉落](./历练妖兽掉落.md)
- 奇遇了结材料总表见 [历练奇遇掉落](./历练奇遇掉落.md)（当前多为待补充）
