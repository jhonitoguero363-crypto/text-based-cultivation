# 丹药设定

丹阁售卖与炼制目录，共 **41** 种（配方 35 条）；另有坊市稀有丹 **23** 种（不可炼制）。

数据来源：`pill-catalog.ts`、`pill-market-rare.ts`（坊市稀有）、`pill-system.ts`（服用机制）、`herb-catalog.ts`（配方）。

## 效果方向（八类）

服用入口：角色页背包点按丹药（**突破丹**、**保命丹**除外）。

| 方向 | 作用 |
|------|------|
| **灵根丹** | 永久提升角色资质（根骨） |
| **悟性丹** | 临时提升功法、法术领悟 |
| **修为丹** | 直接增加修为 |
| **聚灵丹** | 临时提高挂机/闭关收益 |
| **战斗丹** | 历练、切磋、死斗等；含疗伤 |
| **突破丹** | 不可背包手动服；洞府破境时选择是否服用 |
| **保命丹** | 不可背包手动服；历练 / 死斗身死时自动从背包触发；触发后依丹药进入正常或受伤状态 |
| **特殊丹** | 气运、心境、神魂、幻术等（**多数机械效果待开放**，清单见 [待完善功能](./待完善功能.md)） |

### 保命触发结果

| 丹药 | 触发后状态 |
|------|------------|
| 涅槃丹、逆命丹 | **正常**（无伤） |
| 九死还魂丹、九转轮回丹 | **受伤**（需疗伤） |

背包有多枚保命丹时，优先消耗标价更高者；旧存档中「手动服用积攒的保命次数」仍可兜底一次免死（触发后为正常）。

## 品阶说明

一品 → 九品 → 仙丹 → 神丹 → 先天神丹

## 炼制难度

独立于品阶，取值 **1～12**，影响自己炼制成功率（越高越难）。委托炼制不受影响。

| 数值 | 名称 |
|------|------|
| 1 | 入门 |
| 2 | 简单 |
| 3 | 普通 |
| 4 | 偏难 |
| 5 | 困难 |
| 6 | 艰难 |
| 7 | 极难 |
| 8 | 险绝 |
| 9 | 天劫 |
| 10 | 造化 |
| 11 | 鸿蒙 |
| 12 | 无极 |

默认与品阶档位对齐（一品=1 … 先天神丹=12），可在 `pill-catalog.ts` 的 `craftDifficulty` 单独调整。

## 获取方式

1. **丹阁购买**：按境界浏览，消耗灵石（无需炼丹术）
2. **丹阁炼制**：需先修习法术「炼丹术」；配方只耗药材，不另扣灵石
   - **自己炼制**：成功率由炼丹术熟练度与**炼制难度**决定；失败则药材尽毁
   - **委托炼制**：只耗药材，必定成功
3. **坊市稀有丹**：不可炼制、不进丹阁；极小概率出现在坊市货架，小概率出现在商人私货（见下节）
4. **任务 / 历练掉落**（设定方向）

## 坊市稀有丹（不可炼制）

- 数据：`src/constants/pill-market-rare.ts`
- **暂不可炼制**，亦不在丹阁上架
- **坊市货架**：每日刷新时约 **3.5%** 额外上架 1 枚（受玩家境界过滤）
- **商人私货**：抽到丹药槽时约 **14%** 改为稀有丹
- **品阶权重**（越高越稀有）：黄 1 · 玄 0.5 · 地 0.22 · 天 0.08 · 仙 0.025
- **灵根丹 / 悟性丹 / 保命丹**：售价约 **×7**，出现权重再 **×0.12**（相对同阶普通稀有丹）
