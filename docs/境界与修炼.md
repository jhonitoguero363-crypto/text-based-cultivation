# 境界与修炼

## 境界一览

由低到高：

0. **无修为**（凡人，创角初始 / 最低境界）
1. 炼气
2. 筑基
3. 金丹
4. 元婴
5. 化神
6. 炼虚
7. 合体
8. 大乘
9. 渡劫
10. 飞升

## 阶段划分

| 大境界 | 阶段 |
|--------|------|
| 无修为 | 仅一档（展示为「无修为」） |
| 炼气 | 一层 → 九层 |
| 筑基及以后 | 前期 → 中期 → 后期 → 大圆满 |

展示格式示例：`无修为`、`炼气三层`、`筑基前期`、`飞升大圆满`。

## 突破规则

- **本层修为**：进度条只表示当前境界本层所需，**不是**把前面各层需求累加
- 本层攒满后可尝试突破；**成功后修为归零**，按新境界本层需求重新积攒
- **无修为 → 炼气一层**为踏入修仙的第一步，成功率偏高（约 90%）
- 先推进当前大境界的阶段，阶段满后进入下一大境界
- 终点：飞升 · 大圆满
- 各层本层需求随境界升高而增大（约每阶段 ×1.3），但仍是「本层一条进度」
- 实现：`src/constants/realm-exp.ts` 的 `getExpRequiredToBreakthrough`；突破后 `exp=0` 并刷新本层上限

### 突破成功率

修为已满时洞府会显示成功率；确认后按概率判定。失败则**修为降至八成**（降 20%），需重新蓄满再试。

**突破成功**后：

- 境界推进至下一阶段 / 下一大境界
- **修为归零**，并按新境界重算突破所需修为上限，从头再积

| 类型 | 基础成功率 | 说明 |
|------|------------|------|
| 无修为 → 炼气 | 约 90% | 引气入体 |
| 小境界 | 约 80%+ | 同大境界内阶段推进（如炼气一层→二层、筑基前期→中期） |
| 大境界 | 约 10%～50% | 跨大境界（如炼气九层→筑基前期）；越高目标越低 |

修正因素：

- **主灵根（根骨）**：相对基准 **50**，每 ±1 点约 **±0.4** 百分点（约 0→−20%、50→0、100→+20%）
- **功法品阶**：本命功法越高，成功率越高（黄下略减、仙上明显加成）
- **突破丹**：持有对应丹药时尝试会自动服用（成败均消耗），大境界约 +20%～+30%，小境界约 +8%～+10%
  - 例：进筑基用筑基丹，进金丹用结金丹；渡劫丹 / 飞升丹同理
  - 炼气阶段与炼虚（目录暂无突破丹）无专用丹加成

最终成功率钳制在 **5%～95%**。

实现：`src/constants/breakthrough.ts`、`player.breakthrough()`。

## 洞府修炼与功法同步

洞府吐纳修为 = 随机吐纳 × 悟性/灵根/洞府倍率 × **境界基础** × **功法品阶倍率** ×（1 + 功法熟练度修为加成）

| 因素 | 规则 |
|------|------|
| 境界基础 | 随当前境界递增（约每阶段 ×1.24），增速**慢于**突破需求 → 越高越难 |
| 功法品阶 | 黄阶下品 ≈ ×0.85 … 仙阶上品 ≈ ×3.1；高阶功法才能跟上高阶突破 |
| 熟练度 | 另见 [功法设定](./功法设定.md) 修为获取加成 |

因此：境界越高越难；换同境界适配的更高阶功法，修为增速会大致跟上需求曲线。

## 灵根

创建角色时随机八系灵根，并**独立随机悟性**（约 20～99，多数中段）。

灵根品阶大致为：

天品 → 上品 → 中品 → 下品 → 劣品 → 无根

灵根（根骨）八系：金、木、水、火、土、风、冰、雷。

**主灵根**（数值最高的一系）除影响入门身份外，还修正**突破成功率**（见上文）。

### 修炼速度

| 因素 | 影响对象 | 规则 |
|------|----------|------|
| **悟性** | 功法修为、法术熟练度 | 基准 50 = ×1.00，每点 ±1%（约 20→×0.70，99→×1.49） |
| **灵根亲和（五行）** | 功法与法术 | 见下表 |
| 洞府聚气 / 修炼加成 | 功法与法术 | 叠乘在悟性、灵根之后 |

#### 五行相生相克

- **相生**：木→火→土→金→水→木  
- **相克**：木→土→水→火→金→木  
- **归并**：风≈木，冰≈水，雷≈火（用于判定关系）

相对**主灵根**与功法/法术属性：

| 关系 | 效率 |
|------|------|
| **同属**（含归并后同属） | 看对应灵根数值：越好越快（基准 50 = ×1.00，每点 ±0.8%） |
| **相克** | 大幅降低（×0.38） |
| **异属**（含相生等非克） | 小幅降低（×0.82） |
| **无属性**（混沌/天道等） | 不乘灵根项 |

法术演练**不涨修为**，仅涨熟练度（每 5 秒基础 0～0.5，再乘综合倍率）。

功法属性示例：火系→火，剑道→金，炼体→土，身法/空间→风；混沌、天道、纯修炼类等无单一对应根骨。

常量：`src/constants/practice-speed.ts`。

## 境界与内容解锁（对应关系）

| 内容 | 与境界关系 |
|------|------------|
| 法宝品阶 | 法器→先天至宝，受当前大境界上限约束 |
| 器阁购宝 / 打造 | 境界不足不可驾驭高阶 |
| 矿洞掉落权重 | 修为越高，高阶矿概率与单次灵石数量上升 |
| 妖兽遭遇 | 按秘境地点境界及邻近境界抽取；击败后选击杀或抓捕（抓捕仅一次，失败转击杀） |
| 灵宠购买 | 兽阁仅售灵宠，需达对应境界方可契约 |
| 丹药 / 药材 / 矿石 | 按境界或品阶分区展示、兑换 |

## 角色强度（当前实现）

- **战力**：唯一战斗强度指标（本体战力 + 已装备法宝加成）；突破境界会提升本体战力
- 已移除气血 / 灵气 / 攻击 / 防御 / 速度等分散属性
- 悟性影响功法修为与法术熟练度增长速度；对应属性根骨额外影响功法修炼速度
- 另有贡献、身份（如外门弟子）等成长字段；**身份**入门依主灵根与宗门等级，突破后可随大境界晋升至亲传（详见 [宗门设定](./宗门设定.md)）
- 背包分类：丹药 / 功法 / 材料 / 法宝
- 灵宠：同时仅 **1** 只出战，其余待命；可在角色页切换；含好感
- 出战灵兽在秘境战斗（妖兽 / 人物）**胜利**后，按敌我战力差有约 **2%～42%** 概率阵亡；阵亡后自动由下一只接替出战（若有）
- 角色战斗：按战力差判定胜负；战败可能 **阵亡重开**、**受伤**（战力约 -30%；洞府静养或疗伤丹治愈前不可再战）或脱身
