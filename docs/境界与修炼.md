# 境界与修炼

## 十大境界

由低到高：

1. 炼气
2. 筑基
3. 金丹
4. 元婴
5. 化神
6. 炼虚
7. 合体
8. 大乘
9. 渡劫
10. 飞升

## 阶段划分

| 大境界 | 阶段 |
|--------|------|
| 炼气 | 一层 → 九层 |
| 筑基及以后 | 前期 → 中期 → 后期 → 大圆满 |

展示格式示例：`炼气三层`、`筑基前期`、`飞升大圆满`。

## 突破规则

- 修为（经验）攒满后可突破
- 先推进当前大境界的阶段，阶段满后进入下一大境界
- 终点：飞升 · 大圆满

## 灵根

创建角色时随机八系灵根，品阶大致为：

天品 → 上品 → 中品 → 下品 → 劣品 → 无根

灵根（根骨）八系：金、木、水、火、土、风、冰、雷。

### 修炼速度

| 因素 | 影响对象 | 规则（基准 50 = ×1.00） |
|------|----------|-------------------------|
| **悟性** | 功法修为、法术熟练度 | 每点 ±1%（约 20→×0.70，99→×1.49） |
| **对应根骨** | 仅功法修为 | 功法类型/流派匹配的灵根，每点 ±0.8%；无对应属性则不计 |
| 洞府聚气 / 修炼加成 | 功法与法术 | 叠乘在悟性、根骨之后 |

法术演练**不涨修为**，仅涨熟练度（每 5 秒基础 0～0.5）。

功法属性示例：火系→火根骨，剑道→金，炼体→土，身法/空间→风；混沌、天道、纯修炼类等无单一对应根骨。

常量：`src/constants/practice-speed.ts`。

## 境界与内容解锁（对应关系）

| 内容 | 与境界关系 |
|------|------------|
| 法宝品阶 | 法器→先天至宝，受当前大境界上限约束 |
| 器阁购宝 / 打造 | 境界不足不可驾驭高阶 |
| 矿洞掉落权重 | 修为越高，高阶矿概率与单次灵石数量上升 |
| 妖兽遭遇 | 按秘境地点境界及邻近境界抽取；击败后可抓捕 |
| 灵宠购买 | 兽阁仅售灵宠，需达对应境界方可契约 |
| 丹药 / 药材 / 矿石 | 按境界或品阶分区展示、兑换 |

## 角色强度（当前实现）

- **战力**：唯一战斗强度指标（本体战力 + 已装备法宝加成）；突破境界会提升本体战力
- 已移除气血 / 灵气 / 攻击 / 防御 / 速度等分散属性
- 悟性影响功法修为与法术熟练度增长速度；对应属性根骨额外影响功法修炼速度
- 另有贡献、身份（如外门弟子）等成长字段
- 背包分类：丹药 / 功法 / 材料 / 法宝
- 灵宠：出战 / 待命、好感
