# 灵兽图鉴

图鉴将 **妖兽** 与 **灵宠** 合并为「灵兽」。

- 兽阁灵宠：41 种（仅兽阁出售）
- 秘境妖兽：60 种（击败后可选击杀或抓捕；抓捕成功化为灵宠，可回售兽阁）
- 同名去重后在游戏内合并展示；击败/抓捕/购买后解锁详情
