# 历练人物

相关：[宗门人物](./宗门人物.md)（偶遇主池）· 实现：`adventure-npc-catalog.ts`。

## 运行时偶遇逻辑

秘境探索约 **70%** 偶遇人物；人数多为 1，约 25% 为 2。抽取时优先境界邻近（大境界差 ≤ 1）。

| 标签 | 来源 | 说明 |
|------|------|------|
| 宗门弟子 | **本宗**名录 | 执事 / 亲传 / 内门 / 外门 / 杂役；地点 ≥ 元婴时可含长老。池内 **×3** 加权 |
| 正道修士 | **其他**正道宗门 | 青云宗 ↔ 万剑宗（排除本宗）。**×2** |
| 魔道修士 | **其他**魔门宗门 | 优先其他魔门；若无其他同派，回退该派全部宗门名录；仍空则用下方目录魔修。**×2** |
| 妖族 | **其他**妖族宗门 | 优先其他妖族宗门；若无其他同派，回退该派全部名录。**×2** |
| 散修 / 商人 | 本页固定目录 | `place=各地` 且境界邻近。**×2** |
| 隐世 / 奇遇 | 本页固定目录 | 各地可刷，权重最低（**×1**） |

### 未入宗

尚无 `sectId` 时：不走四宗名录。池为目录中「地点匹配 / 同境界宗门弟子 / 邻近魔修」加重，再混入散修、商人、隐世、奇遇。

### 坊市人物

每日 2～4 人，四类打乱后各取一类：**商人 / 正道修士 / 魔道修士 / 散修**（不足再补）。

- 商人、散修：固定目录（境界邻近）
- 正道修士：其他正道宗门名录；无则目录「正道修士 / 宗门弟子」（弟子映射为正道）
- 魔道修士：其他魔门宗门名录；无则目录魔修

### 任务特例

- **清剿敌对势力**（`defeat_hostile`）：优先塞入一名相对玩家派系的敌对人物（`pickHostileEncounterNpc`；正道、魔门、妖族互为敌对；无宗时计魔道/妖族）
- **营救弟子**（`rescue_talk`）：生成「被困弟子」，`kind=宗门弟子`，称号为「{本宗名}外门」
