# 法宝设定

## 四类与装备位

| 类别 | 装备位 | 定位 |
|------|--------|------|
| 攻击类 | 攻击位 | 伤害、破甲、元素爆发 |
| 防御类 | 防御位 | 护体、减伤、抗性 |
| 辅助类 | 辅助位 | 修炼、恢复、探索、洞察 |
| 特殊类 | 特殊位 | 空间、时间、因果、规则、创世等 |

同类仅可装备一件；装备时自动替换同槽位法宝。

## 品阶

| 品阶 | 对应境界 | 特点 |
|------|----------|------|
| 法器 | 炼气～筑基 | 基础属性、简单技能 |
| 灵器 | 金丹～元婴 | 属性强化、特殊技能 |
| 仙器 | 化神～炼虚 | 空间、时间、灵魂等 |
| 道器 | 合体～渡劫 | 规则、领域、因果 |
| 镇界神器 | 大乘 | 影响世界、宗门、轮回 |
| 先天至宝 | 飞升 | 创造规则、世界与大道 |

展示品阶可带品质前缀，如：下品法器、极品灵器。

驾驭 / 打造受当前大境界上限约束。

## 获取途径

1. 器阁购买（目录见下，无需炼器术）
2. 器阁自由打造（需先修习法术「炼器术」）
   - **自己炼制**：只耗材料；成功率由炼器术等级与预估品阶决定
   - **委托炼制**：材料 + 灵石；必定成功
3. 秘境历练掉落（设定方向）
4. 坊市（商店入口）

## 自由打造要点

- 投入矿石越多、品阶越高 → 材料强度越高
- 成功率与成品品阶随强度上升，仍有失败可能
- 失败：材料与灵石尽毁
- 成功：随机生成攻击类 / 防御类 / 辅助类 / 特殊类之一，并带特技文案
