# 历练对战掉落

秘境历练中，与**战斗 / 探索结算**相关的掉落总览。细表按来源拆到子文档。

数据源：

| 来源 | 常量 / 逻辑 |
|------|-------------|
| 概率与货池 | `src/constants/adventure-battle.ts`（`NPC_*` / `EXPLORE_*`、`rollNpcDefeatLoot`、`rollExploreMaterialLoot`） |
| 妖兽材料池 | `src/constants/beast-catalog.ts`（`drops`）→ `adventure.ts` → `rollBeastMaterialDrop` |
| 奇遇材料池 | `src/constants/mission-catalog.ts`（奇遇 `drops`） |
| 专属材料图鉴 | `src/constants/loot-material-catalog.ts` |
| 材料头像 | `src/constants/loot-icons.ts` · `src/assets/loot/icons/` |

页面结算：`src/pages/adventure/explore.vue`（人物额外掉落）、`src/stores/adventure.ts`（妖兽击杀 / 探索拾得 / 奇遇了结）。

## 总览

| 渠道 | 触发 | 掉落物 | 数量 / 抽取 | 详见 |
|------|------|--------|------------|------|
| **击败妖兽 → 击杀** | 战斗胜利后选击杀；或抓捕失败转击杀 | **材料**（偶为已知矿石/药材名则入对应分类） | 固定 1 份；从该兽 `drops` **等概率**抽 1 种 | [历练妖兽掉落](./历练妖兽掉落.md) |
| **击败妖兽 → 抓捕成功** | 抓捕判定成功 | 仅灵宠 | **无**材料 | 同上 |
| **击败人物** | 战斗胜利 | 灵石 + 微量修为；另：**法宝** / **丹药**（独立判定） | 见下表概率；货池为对方境界及以下 | 本节「击败人物」 |
| **探索一次** | `exploreOnce` 结算 | 微量修为 / 灵石；另：**药材** / **矿石**（独立判定） | 见下表概率；品阶随地点境界 | 本节「探索拾得」 |
| **了结奇遇** | 探查后了结 | 修为 / 灵石；可选 **材料** | `drops` 配置时等概率 1 种 | [历练奇遇掉落](./历练奇遇掉落.md) |

秘境地点文案中的「掉落」字段（`adventure-locations.ts`）为氛围说明，**不直接驱动**上述随机池。

## 击败妖兽（材料）

| 项 | 说明 |
|----|------|
| 击败时 | 微量修为、出战法术熟练度；**不给灵石**；**不立刻掉材料** |
| 击杀 | 从 `drops`（顿号分隔）等概率抽 **1** 种入背包 |
| 抓捕成功 | 收为灵宠，**不掉材料** |
| 抓捕失败 | 自动转击杀并掉材料 |

完整「妖兽 → 可能掉落」与「材料 → 来源妖兽」见 [历练妖兽掉落](./历练妖兽掉落.md)。  
专属材料名录（已排除矿石/药材重名）见 [图鉴-材料](./图鉴-材料.md)。

重导：

```bash
node scripts/export-beast-drop-docs.mjs
node scripts/export-loot-material-docs.mjs
```

## 击败人物（法宝 / 丹药）

胜利固定：灵石（`rollNpcStoneGain`，随对方境界与同行倍率）、微量修为、出战法术熟练度。

额外掉落（彼此独立，可同时有 / 皆无）：

| 项 | 概率常量 | 当前值 | 货池 |
|----|----------|--------|------|
| 法宝 | `NPC_TREASURE_DROP_CHANCE` | **12%** | `FORGE_SHOP_CATALOG` 中 **对方大境界及以下** 有货的最近一档，等概率 1 件 |
| 丹药 | `NPC_PILL_DROP_CHANCE` | **3%** | `PILL_SHOP_CATALOG` 同上规则，等概率 1 枚 |

- 货池函数：`poolByRealmOrBelow`（无该境条目则向下取最近有货境界）。
- 法宝写入仓库（新实例 id）；丹药入背包「丹药」。
- **不掉**妖兽式「材料」字段；人物战力与属性见 [玩法系统](./玩法系统.md) 历练战斗段。

## 探索拾得（药材 / 矿石）

每次成功探索结算时，与遭遇列表**独立**判定（可同时拾得药材与矿石）：

| 项 | 概率常量 | 当前值 | 品阶规则 |
|----|----------|--------|----------|
| 药材 | `EXPLORE_HERB_DROP_CHANCE` | **4%** | 随地点大境界放宽可选 `level`（炼气偏灵草～灵液；筑基～金丹含灵藤/灵木；更高可含仙阶草药等） |
| 矿石 | `EXPLORE_ORE_DROP_CHANCE` | **4%** | 按境界索引限制最高矿阶（灵矿→…→镇界神材），在允许阶内等概率抽品阶再抽矿 |

入背包分类分别为「药材」「矿石」，**不进**材料图鉴专表（除非将来与专属材料重名策略变更）。
