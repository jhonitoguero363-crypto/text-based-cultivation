# 秘境设定

历练 · 秘境探索地点总表，共 **26** 处。

数据来源：`src/constants/adventure-locations.ts`。

## 规则摘要

| 项 | 说明 |
|----|------|
| 入口 | 历练 Tab → 秘境历练 |
| 每日次数 | 默认剩余 **8** 次（`remainTimes`） |
| 进入条件 | 玩家境界 ≥ 地点建议境界 |
| 单次探索 | 消耗 1 次；刷新 **1～3** 只妖兽 |
| 偶遇人物 | 约 **70%** 概率；通常 1 人，偶发 2 人 |
| 奇遇 | 约 **28%** 触发（见 [任务设定](./任务设定.md) 奇遇） |
| 基础收益 | 修为 / 灵石随危险星级与境界估算 |
| 妖兽掉落 | 击败后获材料；妖兽按地点境界及邻近境界抽取 |
| 抓捕 | 击败后可抓捕化为灵宠（稀有度影响成功率）；可回售兽阁 |

## 收益估算

`estimateExploreReward`：

- 修为 = `30 + 星级×18 + 境界序号×25`
- 灵石 = `16 + 星级×10 + 境界序号×14`

境界序号：炼气=0 … 合体=6（本表最高至合体）。
