# 历练奇遇掉落

秘境探索触发 **奇遇** 并了结后，可能掉落的材料总表。

数据来源：`src/constants/mission-catalog.ts`（奇遇条目字段 `drops`）。
结算：`rollEncounterResolveReward` → 探索页了结奇遇时发放。

## 如何补充

在 `MISSION_CATALOG` 中找到对应奇遇，把 `drops: ''` 改成顿号分隔的材料名，例如：

```ts
drops: '残卷、灵草、秘信'
```

留空表示 **待补充**（当前不会掉材料，仅有修为 / 灵石）。改完后执行：

```bash
node scripts/export-encounter-drop-docs.mjs
```

## 规则摘要

| 项 | 说明 |
|----|------|
| 触发 | 探索约 **28%** 触发奇遇；了结（探查）时结算 |
| 基础奖励 | 修为约 40～119 · 灵石约 30～99（与材料独立） |
| 材料 | 已配置 `drops` 时，从列表 **等概率抽 1 种** 入背包「材料」 |
| 未配置 | `drops: ''` → 文档标「待补充」，游戏内不掉材料 |
| 条目 | 奇遇 **10** · 已填 **0** · 待补充 **10** · 材料种类 **0** |
