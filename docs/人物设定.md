# 人物设定

包含两类人物：

1. **宗门人物**：`member-catalog.ts`（当前已录入青云宗）
2. **历练偶遇**：`adventure-npc-catalog.ts`

共 **76** 人（宗门 19 + 历练 57）。

## 规则摘要

| 项 | 说明 |
|----|------|
| 宗门人物 | 「人物」页按分组浏览，可拜访 |
| 历练偶遇 | 秘境探索时随机刷新；约 70% 可遇到人物 |
| 图鉴 | 「人物」页合并展示，默认可见 |
| 扩展 | 天魔宗 / 万剑宗 / 妖族人物名录待补 |
