# 奇遇设定

历练秘境探索触发的 **奇遇** 名录，共 **10** 条。**不进**宗门任务堂。

数据来源：`src/constants/mission-catalog.ts` → `ADVENTURE_ENCOUNTER_CATALOG`。

宗门任务堂见 [任务设定](./任务设定.md)；了结材料见 [历练奇遇掉落](./历练奇遇掉落.md)。

## 规则摘要

| 项 | 说明 |
|----|------|
| 触发 | 秘境探索约 **28%**（`ADVENTURE_ENCOUNTER_CHANCE`） |
| 入口 | 探索页「旅途奇遇」· 探查 / 了结 |
| 基础奖励 | 了结时额外修为与灵石（与材料独立） |
| 材料 | 条目 `drops` 配置后等概率抽 1 种；空则为待补充 |
| 玩法 | 当前多为文案占位；分支可玩化见 [待完善功能](./待完善功能.md) |

## 数据源与常量

- `ADVENTURE_ENCOUNTER_CATALOG`：历练奇遇池

- 材料掉落细表：[历练奇遇掉落](./历练奇遇掉落.md)
