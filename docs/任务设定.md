# 任务设定

宗门**任务堂**名录，共 **20** 条（不含历练奇遇）。

数据来源：`src/constants/mission-catalog.ts` → `SECT_MISSION_CATALOG`。

历练奇遇见 [奇遇设定](./奇遇设定.md)；奇遇材料见 [历练奇遇掉落](./历练奇遇掉落.md)。

## 规则摘要

| 项 | 说明 |
|----|------|
| 时间 | 现实 **6 小时 = 1 修历日**（`game-time.ts`） |
| 任务堂槽位 | 每修历日展示 **5** 条（`DAILY_MISSION_COUNT`） |
| 换日规则 | **未完成任务保留**；已完成移除后补新 |
| 接取上限 | **同时仅 1 个**进行中任务 |
| 流程 | 任务堂接取 → 角色页完成 / 取消 |
| 完成后续 | 槽位用新任务补齐；无每日完成次数硬上限 |
| 奖励结算 | 贡献 / 灵石 / 修为 / 声望等，见各条 `reward` |
| 分类 | **通用**：各宗可刷；**特色**：依赖本宗特色建筑（`requiresFacility`） |
| 弟子池门禁 | **护送灵材 / 丹阁送药 / 找出卧底**：非自身弟子 **&lt; 2** 时不刷出、不可接取 |
| 文案宗门化 | 目录用中性设施名；展示时按当前宗门替换，见 `mission-localize.ts` |
| 完成条件细表 | [宗门任务-完成条件](./宗门任务-完成条件.md) |

## 类型说明

- **通用任务**（16）：各宗任务堂均可出现；标签仍为每日 / 悬赏 / 周常 / 随机
- **特色任务**（4）：绑定各宗特色建筑，仅本宗拥有对应设施时刷出

标签含义（板面展示用，与通用/特色正交）：

- **每日**（9）：日常，贡献与灵石为主
- **悬赏**（3）：高风险高回报，偏战斗与营救
- **周常**（7）：周期较长、奖励更丰
- **随机**（1）：任务板偶发特殊任务

## 数据源与常量

- `SECT_MISSION_CATALOG`：任务堂池；无 `requiresFacility` 为通用，有则为特色
- `MISSION_CATALOG`：任务堂 + 奇遇总库（奇遇见 [奇遇设定](./奇遇设定.md)）
- `DAILY_MISSION_COUNT = 5`
- 设施与特色建筑：`src/constants/sect-facilities.ts`
- 文案本地化：`src/constants/mission-localize.ts`
