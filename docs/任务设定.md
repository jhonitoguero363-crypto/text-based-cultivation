# 任务设定

宗门任务与历练奇遇总库，共 **35** 条。

数据来源：`src/constants/mission-catalog.ts`。

## 规则摘要

| 项 | 说明 |
|----|------|
| 时间 | 现实 **6 小时 = 1 天元日**（农历风格，`game-time.ts`） |
| 任务堂槽位 | 每修历日展示 **5** 条（`DAILY_MISSION_COUNT`） |
| 换日规则 | **未完成任务保留**；已完成移除后补新 |
| 接取上限 | **同时仅 1 个**进行中任务 |
| 流程 | 任务堂接取 → 角色页完成 / 取消 |
| 完成后续 | 槽位用新任务补齐；无每日完成次数硬上限 |
| 奖励结算 | 贡献 / 灵石 / 修为 / 声望等，见各条 `reward` |
| 奇遇 | 标签「奇遇」**不进任务堂**；历练探索时以 **28%** 概率触发 |
| 奇遇了结 | 探索页探查/了结，额外获得修为与灵石 |

## 类型说明

- **每日**（12）：宗门任务堂常见日常，贡献与灵石为主
- **悬赏**（4）：高风险高回报，偏战斗与营救
- **周常**（7）：周期较长、奖励更丰
- **随机**（2）：任务板偶发特殊任务
- **奇遇**（10）：不进任务堂；秘境探索约 28% 概率触发

## 数据源与常量

- `MISSION_CATALOG`：全部任务 + 奇遇
- `SECT_MISSION_CATALOG`：任务堂池（排除奇遇）
- `ADVENTURE_ENCOUNTER_CATALOG`：历练奇遇池
- `DAILY_MISSION_COUNT = 5`
- `ADVENTURE_ENCOUNTER_CHANCE = 0.28`
