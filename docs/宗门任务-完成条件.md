# 宗门任务表 · 完成条件

任务堂池共 **20** 条，按 **通用 / 特色** 分类。数据源：`src/constants/mission-catalog.ts` → `SECT_MISSION_CATALOG`。

完成方式：达成「完成条件」进度后，在角色页点「完成任务」领取奖励。

展示文案按当前宗门本地化（`mission-localize.ts`）：目录写「宗门矿洞」，界面显示「青云矿洞 / 天魔矿洞 / 万剑矿洞 / 万妖矿洞」等；「丹阁」「灵兽阁」为各宗通用设施名。

名录总览见 [任务设定](./任务设定.md)。
