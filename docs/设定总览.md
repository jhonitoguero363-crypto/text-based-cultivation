# 设定总览

## 产品定位

**青云修仙**是一款文字驱动的修仙养成游戏，主打：

- 境界突破与战力成长
- 宗门日常（任务、矿洞、药园、丹阁、器阁、灵兽）
- 秘境历练（遭遇妖兽、人物、奇遇）
- 图鉴收集（灵兽 / 法宝 / 丹药 / 药材 / 矿石 / 人物）

面向微信小程序与 H5。

## 技术栈

- Taro 4 + Vue 3 + Pinia
- Sass 设计 token（暗夜海军蓝 / 金 / 玉）
- NutUI（部分组件）

## 主界面结构

| Tab | 功能 |
|-----|------|
| 历练 | 坊市 / 秘境探索 |
| 宗门 | 设施枢纽与各子玩法 |
| 角色 | 属性、任务、灵宠、背包、图鉴入口 |

### 宗门设施

丹阁 · 器阁 · 功法阁 · 洞府 · 任务堂 · 人物 · 矿洞 · 药园 · 思过崖 · 镇妖塔 · 灵兽阁

## 核心循环（简）

```
创建角色 → 拜入宗门
    ↓
挖矿/药园/任务 获取材料与灵石
    ↓
器阁打造法宝 · 丹阁炼丹 · 灵兽契约
    ↓
秘境历练提升修为、遭遇妖兽与奇遇
    ↓
突破境界 → 解锁更高品阶内容
    ↓
图鉴收录 · 持续养成
```

## 时间系统

- 以设备系统时间为准
- **现实 6 小时 = 天元历 1 日**（`src/constants/game-time.ts`）
- 日期按农历风格记：干支年 + 正月～腊月 + 初一～三十（一年十二月、每月三十日）
- 页头统一显示「天元日历 · ××年×月×日」
- 坊市货架、宗门任务板按天元日更新；任务未完成不会被换日清掉

## 资源与货币

| 名称 | 用途 |
|------|------|
| 灵石 | 坊市等通用货币（不分品级）；矿洞、历练、委托炼制等消耗 |
| 贡献点 | 宗门货币：任务奖励；功法阁等宗门设施消耗 |
| 修为 / 经验 | 突破境界 |
| 材料 | 矿石、药材等，用于炼器炼丹 |
| 法宝 | 装备增益（四槽位） |
| 灵宠 | 出战助修 |

## 图鉴系统

图鉴页七类：

1. **灵宠** — 拥有后收录
2. **法宝** — 拥有后收录
3. **丹药** — 背包持有后收录
4. **药材** — 材料持有后收录
5. **矿石** — 材料持有后收录
6. **人物** — 默认可见
7. **妖兽** — 默认可见

列表仅展示图标与名称，点击查看详情。
