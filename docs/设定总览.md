# 设定总览

> 玩法细则以 `docs/` 各文档为准；新增或调整设定时须同步更新文档（见 `docs/README.md`）。

## 产品定位

**文字修仙**是一款文字驱动的修仙养成游戏，主打：

- 境界突破与战力成长（各大境界战力范围与同境档位见 [境界与修炼](./境界与修炼.md)）
- 宗门日常（任务、矿洞、药园、丹阁、器阁、灵兽）
- 秘境历练（遭遇妖兽、人物、奇遇）
- 图鉴收集（灵兽 / 法宝 / 功法 / 法术 / 丹药 / 药材 / 矿石 / 材料 / 人物）
- 丹药八类效果：灵根 / 悟性 / 修为 / 聚灵 / 战斗 / 突破 / 保命 / 特殊（见 [丹药设定](./丹药设定.md)）
- 坊市稀有丹：不可炼制，极小概率出现在坊市/商人处（灵根 / 悟性 / 保命 更贵更稀）

面向微信小程序与 H5。

项目 Logo：`src/assets/brand/logo.png`（创角页展示；`src/constants/brand.ts`）。

**待完善 / 待开放清单**见 [待完善功能](./待完善功能.md)（奇遇、特殊丹、高阶秘境、渡劫等）。

## 技术栈

- Taro 4 + Vue 3 + Pinia
- Sass 设计 token（暗夜海军蓝 / 金 / 玉）
- NutUI（部分组件）

### 宗门设施

共用：丹阁 · 器阁 · 功法阁 · 洞府 · 任务堂 · 人物 · 矿洞 · 药园 · 思过崖 · 灵兽阁

各宗特色：青云宗·镇妖塔 · 天魔宗·魔窟 · 万剑宗·剑冢 · 妖族·返祖池（均已开放最小循环）

## 核心循环（简）

```
创建角色 → 拜入宗门
    ↓
挖矿/药园/任务 获取材料与灵石
    ↓
器阁打造法宝 · 丹阁炼丹 · 灵兽契约
    ↓
秘境历练提升修为、遭遇妖兽与奇遇
    ↓
突破境界 → 解锁更高品阶内容
    ↓
图鉴收录 · 持续养成
```

## 时间系统

- 以设备系统时间为准
- **现实 6 小时 = 天元历 1 日**（`src/constants/game-time.ts`）
- 日期按农历风格记：干支年 + 正月～腊月 + 初一～三十（一年十二月、每月三十日）
- 页头统一显示「天元日历 · ××年×月×日」
- 坊市货架、宗门任务板按天元日更新；任务未完成不会被换日清掉

## 资源与货币

| 名称 | 用途 |
|------|------|
| 灵石 | 坊市等通用货币（不分品级）；矿洞、历练、委托炼制等消耗 |
| 贡献点 | 宗门货币：任务奖励；功法阁等宗门设施消耗 |
| 修为 / 经验 | 突破境界 |
| 矿石 | 矿洞挖掘；器阁炼器 |
| 药材 | 药园兑换 / 探索拾取；丹阁炼丹 |
| 材料 | 历练妖兽击杀 / 奇遇了结掉落 |
| 法宝 | 装备增益（四槽位） |
| 灵宠 | 出战助修 |

## 图鉴系统

图鉴页九类：

1. **灵兽** — 灵宠 / 妖兽见过后收录
2. **法宝** — 拥有后收录
3. **功法** — 背包收录后解锁
4. **法术** — 背包收录后解锁
5. **丹药** — 背包持有后收录
6. **药材** — 背包「药材」持有后收录
7. **矿石** — 背包「矿石」持有后收录
8. **材料** — 历练掉落专属材料，持有后收录
9. **人物** — 默认可见

列表仅展示图标与名称，点击查看详情。
