# 历练妖兽掉落

秘境击败妖兽后，选择 **击杀**（或抓捕失败转击杀）时掉落的材料总表。

数据来源：`src/constants/beast-catalog.ts`（字段 `drops`）。结算逻辑：`src/stores/adventure.ts` → `rollBeastMaterialDrop`。

## 规则摘要

| 项 | 说明 |
|----|------|
| 触发 | 战斗胜利后选 **击杀**；或 **抓捕失败** 自动转击杀 |
| 抓捕成功 | 只得灵宠，**不掉材料** |
| 掉落数量 | 固定 **1** 份 |
| 抽取方式 | 从该妖兽 `drops` 列表中 **等概率随机 1 种** |
| 灵石 | 击杀妖兽 **不给灵石**（仅微量修为在击败时结算） |
| 条目 | 妖兽 **60** 种 · 材料种类 **107** |
